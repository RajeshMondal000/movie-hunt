# Application screenshots

The repository owner should capture these five screens from the deployed application and save them here with the exact filenames below. Use genuine screenshots of the current build; do not use mockups or generated concept art as product screenshots.

| Filename | Screen to capture | Suggested state |
|---|---|---|
| `01-movies-home.png` | Movies home | Movies mode selected; homepage showing movie rows/cards |
| `02-anime-discovery.png` | Anime discovery | Anime mode selected; discovery results and genre/search controls visible |
| `03-movie-watchlist.png` | Movie watchlist | At least a few movie entries with their statuses visible |
| `04-ai-anime-recommendation.png` | AI anime recommendation | A completed anime prompt with recommendation cards and explanation/source indicator |
| `05-friends-community.png` | Friends and community | Friends page showing member/friend activity or shared recommendations, using accounts whose owners agreed to appear |

## Capture guidance

- Capture from the deployed site at a consistent desktop viewport (for example, 1440 × 900).
- Keep the page title/navigation and the key feature visible; avoid capturing browser developer tools.
- Use sample/test content where possible. Hide or blur private email addresses and any personal details that should not be public.
- Do not expose API keys, session cookies, OAuth values, or account IDs.
- Save PNG files using the exact filenames above. The root README can then embed them with relative Markdown image paths.
